# Radar das Américas — agentes

Pipeline multiagente (LangGraph) do [Radar das Américas](https://radardasamericas.com), um projeto [Agents2AI](https://agents2ai.com).

Este repositório é **público**: código do grafo, schemas Pydantic, checagem de atribuição e adaptadores de canal. Prompts, chaves e dados sensíveis ficam no repositório privado `radar-americas-prompts`, carregados via `RADAR_PRIVATE_DIR`.

O site está em [`radar-americas`](https://github.com/LucianoTeixeiras/radar-americas).

Nada é publicado sem aprovação humana.
